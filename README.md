# My-Python-Pandas-Projects-repo-

# Retail & Sales Data Analysis with Python

## Overview

This project was completed as part of a Data Technician Bootcamp and demonstrates the use of Python and Pandas for data exploration, cleaning, manipulation, and analysis. Working with retail and sales datasets, the project focuses on developing practical data analysis skills commonly used in business intelligence and data-driven decision-making.

## Objectives

- Import and explore retail and sales datasets
- Clean and prepare data for analysis
- Filter and extract meaningful subsets of data
- Identify trends and patterns in sales performance
- Create visualisations to communicate insights effectively

## Skills Demonstrated

### Data Exploration
- Loaded and examined datasets using Pandas DataFrames
- Investigated data structure, column types, and summary statistics
- Identified missing values and data quality issues

### Data Filtering & Indexing
- Applied conditional filtering to analyse specific products, categories, and sales records
- Used `.loc[]` for label-based selection
- Used `.iloc[]` for position-based slicing and extraction
- Selected subsets of data for targeted business analysis

### Data Cleaning & Preparation
- Removed unnecessary columns and duplicate records
- Managed missing values using:
  - `dropna()`
  - `fillna()`
- Renamed and reformatted columns to improve readability
- Ensured datasets were analysis-ready

### Data Manipulation
Utilised a range of Pandas methods to transform and analyse data, including:

- `groupby()` for aggregating sales and product information
- `sort_values()` for ranking products and sales performance
- `value_counts()` for frequency analysis
- `drop()` for removing unwanted data
- `describe()` for statistical summaries
- `reset_index()` for restructuring DataFrames
- Additional filtering, indexing, and aggregation techniques

### Data Analysis
- Calculated key sales metrics and performance indicators
- Compared product categories and sales trends
- Identified high-performing and low-performing products
- Generated insights from retail transaction data

### Data Visualisation
- Created charts and graphs using Pandas plotting functionality
- Produced visualisations with libraries such as Matplotlib
- Presented trends, comparisons, and summary statistics through clear data visuals
- Communicated business findings using graphical analysis

## Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebooks

## Key Learning Outcomes

Through this project, I gained hands-on experience in:
- Working with real-world retail and sales datasets
- Cleaning and preparing data for analysis
- Using Pandas for efficient data manipulation
- Applying indexing techniques with `.loc[]` and `.iloc[]`
- Performing data aggregation and transformation
- Visualising data to support business decision-making
- Developing practical analytical skills used in data technician and business intelligence roles

## Project Outcome

This project demonstrates the complete data analysis workflow, from raw data exploration and preparation through to insight generation and visual reporting. It highlights the application of Python and Pandas to solve real-world retail and sales analysis problems while building core data technician competencies.
